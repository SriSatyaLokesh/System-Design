# 🎓 Free AI Certifications & Learning Paths

Welcome to your definitive guide for mastering AI without spending a dime. Our goal is simple: provide you with a structured path to gain high-value skills and recognized certifications for free.

## 🚀 The Core Path: Start Here

Before diving into broad certifications, master the specific tools and frameworks we use in this Agentic AI repository.

### 1. Entropic Skills (Anthropic)
**Start with this.** To build effective agents, you must master the art of prompt engineering and understand how Large Language Models (LLMs) think. Anthropic, the creators of Claude, offer the best interactive course for this.

*   **Course:** [Anthropic Prompt Engineering Interactive Tutorial](https://github.com/anthropics/courses)
*   **Focus:** Prompt construction, logic, and steering AI behavior.
*   **Cost:** **Free**
*   **Why it's essential:** It's the foundational skill for every other tool in this list.

### 2. This Repository (SriSatyaLokesh/Agentic AI)
Once you understand the basics of prompting from Anthropic, return here. This repository is designed as a complete practical curriculum for building **Agentic Systems**.

*   **Action:** Go through the [Agentic AI README](../README.md) and follow the modules sequentially (01-Ecosystem to 06-Capstone).
*   **Focus:** Practical application, coding agents, and system design patterns.
*   **Differentiation:** While others teach theory, we teach you how to *build*.

## 🛠️ Essential Tool Documentation

Great developers read documentation. These are the gold-standard resources for the specific tools that power modern AI development.

### Cursor AI
The AI code editor that changes how you write code.
*   **Resource:** [Cursor Documentation & Learning](https://docs.cursor.com/)
*   **What you'll learn:** How to use "Chat with Codebase", "Composer", and AI-driven refactoring.

### "Anti-Gravity" (DeepLearning.AI / Andrew Ng)
Often referred to as the "Anti-Gravity" force in AI education because they lift everyone up—Andrew Ng's **DeepLearning.AI** offers a massive list of short, high-impact courses.
*   **Resource:** [DeepLearning.AI Short Courses](https://www.deeplearning.ai/short-courses/)
*   **Top Picks:**
    *   *ChatGPT Prompt Engineering for Developers* (with OpenAI)
    *   *Building Systems with the ChatGPT API*
    *   *LangChain for LLM Application Development*
*   **Cost:** **Free** (for a limited time during course launch windows, usually permanently free to audit).
