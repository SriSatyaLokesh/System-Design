## Out of Scope (v1.0)

- Backend services — Static content only, no server-side logic
- User accounts / authentication — Public access site
- LMS features — No quizzes, certificates, grading, or formal assessment
- Video hosting — Link to external platforms (YouTube, Skillshare)
- AI model training content — Focus on using AI, not building models
- Deep ML/neural networks — Not the target learning outcome
- Live coding environments — Use external tools (CodeSandbox, StackBlitz)
- Comments system — No dynamic discussion (GitHub Discussions if needed)
- Analytics/tracking — No user behavior tracking or cookies
- Custom build pipeline — Leverage GitHub native markdown rendering initially
