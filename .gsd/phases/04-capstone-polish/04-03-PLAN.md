## Task 1: Audit and enforce curation standards across all sections

**Action:** Review all 7 README files and ensure quality standards are met.

**Requirements to satisfy:**
- **QUAL-01**: Strict curation criteria (5-7 resources max per topic, no link dumps)
- **QUAL-02**: Each resource link includes context (what it is, why it matters, when to use it)
- **QUAL-03**: Difficulty markers on content sections (beginner/intermediate/advanced labels)
- **QUAL-04**: Prerequisite chains documented (clear dependencies between sections)
- **QUAL-05**: "What's next" guidance at end of each section (clear progression path)

**Audit checklist for each file:**

### 1. Resource Curation (QUAL-01)
- Count resources in Resources section
- If > 7: consolidate to most valuable 5-7
- If < 5: verify intentional (some sections may need fewer)
- Remove any "see also" link dumps

### 2. Resource Context (QUAL-02)
- Every resource has format: **[Title]** ([Type]) - [Context sentence]
- Context explains: what reader will learn, why it matters, when to reference it
- Example: **GSD Framework Docs** (Guide) - Comprehensive reference for CLI commands and workflow patterns when you're ready to adopt structured AI execution

### 3. Difficulty Markers (QUAL-03)
Add difficulty indicators to major sections:
- 🟢 Beginner - No prior knowledge needed
- 🟡 Intermediate - Requires basic AI tool familiarity
- 🔴 Advanced - Assumes comfort with AI workflows and development

Format:
`markdown
## Section Name 🟢 Beginner

[Content...]
`

### 4. Prerequisite Documentation (QUAL-04)
At top of each section README, add:
`markdown
## Prerequisites

**Required:**
- [Section N: Name](../0N-name/README.md) - Specific concepts needed

**Optional:**
- [Background knowledge] - Helpful but not required
`

### 5. What's Next Guidance (QUAL-05)
At end of each section README (before navigation), add:
`markdown
## What's Next?

**You've learned:** [3-4 key takeaways]

**Ready to:**
- [Immediate next step with link]
- [Alternative path if user wants to skip ahead]

**Suggested practice:**
- [1-2 concrete actions to reinforce learning]
`

**Audit artifact to create:**

Create `.gsd/phases/04-capstone-polish/QUALITY-AUDIT.md` documenting:
1. Section-by-section findings
2. Changes made (resources consolidated, context added, markers inserted)
3. Compliance status per requirement (QUAL-01 through QUAL-05)
4. Final verification checklist
