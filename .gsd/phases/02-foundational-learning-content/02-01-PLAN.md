  <action>
Write comprehensive AI ecosystem content following the "What  Why  When  How" structure from research.

**Structure:**

1. **Section Introduction**
   - 1-paragraph overview of AI categories
   - TL;DR box with key takeaways

2. **AI Assistants (ECO-01)**
   - Definition: Conversational AI accessed via chat interface
   - Key characteristics: User-driven, session-based, exploratory
   - Real examples: ChatGPT (general), Claude (advanced reasoning), Perplexity (research)
   - Use cases: Brainstorming, learning concepts, quick questions, document summarization
   - When to use: Need expert consultation, exploring unfamiliar territory
   - Metaphor: "Ask an Expert" - you drive the conversation

3. **AI Agents (ECO-02)**
   - Definition: Autonomous AI that executes tasks independently
   - Key characteristics: Goal-driven, autonomous, multi-step execution
   - Real examples: AutoGPT (task automation), AgentGPT (web-based), custom agents
   - Use cases: Research compilation, data processing, multi-step workflows
   - When to use: Clear goal but complex execution, want results not conversation
   - Metaphor: "Hire a Contractor" - they deliver outcomes

4. **AI Copilots (ECO-03)**
   - Definition: AI integrated into your workflow/IDE providing real-time assistance
   - Key characteristics: Context-aware, inline suggestions, stay-in-flow
   - Real examples: GitHub Copilot (code), Claude Code (repository), Microsoft Copilot (Office)
   - Use cases: Code generation, multi-file refactoring, inline documentation
   - When to use: Working in IDE/tool, need contextual suggestions
   - Metaphor: "Pair Programming" - real-time collaboration

5. **Comparison Framework**
   Create table with consistent dimensions:
   | Dimension | Assistants | Agents | Copilots |
   |-----------|------------|--------|----------|
   | Autonomy | Low (you lead) | High (they execute) | Medium (suggestions) |
   | Integration | Browser/app | External/standalone | IDE/tool |
   | Interaction | Conversational | Goal-based | Inline/contextual |
   | Persistence | Session-based | Task-focused | File/project-based |
   | Best For | Exploration, learning | Automation, results | Development, creation |
   | Workflow | Synchronous | Asynchronous | Real-time |

**Content principles to follow:**
-  Start with 1-sentence definition before details
-  Use concrete product examples, not abstract descriptions
-  Include "When NOT to use" for each category
-  Progressive disclosure: simple  detailed
-  Avoid technical jargon without definitions
-  No feature lists without context
-  No history lessons before explaining what it IS

Use actual metaphors from research: Assistant = Advisor, Agent = Employee, Copilot = Pair Programmer
